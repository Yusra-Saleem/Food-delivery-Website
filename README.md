# Food Delivery App

> On-demand restaurant menu ordering, cart management, and meal delivery web platform.

## Overview

A comprehensive food ordering web platform featuring restaurant menus, item customization, shopping cart management, and order checkout flows.

## Key Features

- Categorized restaurant menus (Starters, Main Courses, Desserts, Beverages)
- Dynamic cart calculation with delivery fees, taxes, and discounts
- Responsive visual layout with appetizing food cards and badges
- Order summary preview and address submission form

## Architecture and Technology Stack

- **Core Technologies:** Next.js, React, TypeScript, Tailwind CSS, Lucide Icons

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/food-delivery-app.git
cd food-delivery-app
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
